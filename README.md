## Team Development Setup

### 1. Clone the Repository

```bash
git clone https://github.com/soumiik03/CivicApply.git
cd CivicApply
npm install
npm run dev
```

### 2. Make Your Changes

Work on the UI/frontend as assigned.

### 3. Push Your Changes

After completing your changes:

```bash
git add .
git commit -m "Improve CivicApply dashboard"
git push
```
